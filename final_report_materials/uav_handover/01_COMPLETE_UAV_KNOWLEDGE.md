## 1. Objective and problem statement

The UAV module performs high-resolution pixel-level semantic
segmentation of agricultural RGB images and orthomosaics.

Objectives:

- Distinguish agricultural surface and vegetation classes.
- Identify regions exhibiting visual drought-like stress.
- Estimate class-wise physical areas.
- Generate field-level visual stress indicators.
- Produce interpretable masks, overlays and reports.
- Process extremely large orthomosaics efficiently.

RGB imagery alone cannot establish physiological or
meteorological drought causation.

The system provides visual drought-stress assessment,
not independently confirmed agricultural drought diagnosis.

## 2. Development history

The initial approach investigated multiscale patch classification.

Patch classification was limited by insufficient spatial context
and the inability to produce precise pixel-level boundaries.

The trained patch classifier was subsequently used to generate
pseudo-labels for unlabeled UAV images.

Pseudo-labeling included sliding-window prediction,
spatial postprocessing and structural cues where applicable.

A custom human-in-the-loop annotation tool was used to
manually correct automatically generated segmentation masks.

The project subsequently adopted semantic segmentation
using manual, pseudo-labeled and synthetic composite samples.

Historical versions include V5, V6, V7, V8, V9, V9.1,
V10, V11 and V12.

SegFormer-B2, SegFormer-B3 and DeepLabV3+ were investigated.

V11 SegFormer-B2 was selected based on recorded validation
performance.

Class-specific logit adjustment was subsequently introduced
to improve drought precision.

Large orthomosaic inference exposed computational and
memory constraints.

The final pipeline introduced rolling probability accumulation,
vectorized morphology, disk-backed connected components,
boundary-aware processing and checkpoint-based recovery.

All 14 orthomosaics were processed successfully,
producing 56 final output files.

Historical configurations and experimental records are
available in 11_experimental_history.

Do not invent undocumented motivations or numerical results
for individual historical versions.

## 4. Dataset construction

Three types of training samples were used:

1. Manually corrected image-mask pairs.
2. Automatically pseudo-labeled UAV images.
3. Synthetic composite image-mask pairs.

The recorded clean dataset contained 279 matched pairs.

Final clean dataset split:

- Training: 224 tiles.
- Validation: 55 tiles.

The validation split used drought-fraction information
to retain drought-rich examples.

A later provenance audit identified 17 shared source
drone images and 22 validation tiles with source overlap.

The remaining 33 validation tiles were classified as
source-disjoint by available filename-based analysis.

Their independence is not fully guaranteed.

Synthetic composites were generated by pasting labeled
patches onto random crops of unlabeled UAV imagery.

Composite strategies included:

- Confusing class pairs.
- Small cotton-boll examples.
- Random multiclass mixtures.

Random mixtures use approximately 3 to 7 patches.

Unlabeled composite background pixels initially receive
ignore index 255.

Configured batch composition:

- 4 manual samples.
- 4 pseudo-labeled samples.
- 8 synthetic composite samples.

Configured synthetic composites per epoch: 1000.

These are configuration values, not necessarily the number
of unique samples actually consumed.

The project used a custom Python desktop annotation tool

The tool was used for human-in-the-loop refinement of

Technology stack:

- Python.

- Matplotlib with TkAgg for interactive visualization.
- OpenCV for image processing and file export.

The interface displays the original RGB image alongside

- Undo history of up to 50 brush strokes.
- Reset to the original tile mask.

## 6. Nine-channel feature representation

The final model uses nine channels derived from RGB imagery.

Channel order:

1. Red.
2. Green.
3. Blue.
4. Excess Green (ExG).
5. Excess Green minus Excess Red (ExGR).
6. Color Index of Vegetation Extraction (CIVE).
7. Green Leaf Index (GLI).
8. Normalized Green-Red Difference Index (NGRDI).
9. HSV Value channel (V).

RGB channels use ImageNet normalization.

Mean = [0.485, 0.456, 0.406]
Std  = [0.229, 0.224, 0.225]

The vegetation indices are computed using RGB values
scaled to [0,1].

The final tensor has shape (9,H,W) and float32 dtype.

Exact vegetation-index equations, clipping ranges
and HSV-V normalization are defined in:

src/preprocessing/indices.py
src/preprocessing/tensor_builder.py

The project also contains a 12-channel representation
with local luminance standard deviation, a GLCM contrast
proxy and FFT-based row periodicity.

These belong to supporting or historical processing paths.

The final V11 segmentation model uses nine channels.

Do not claim that the system uses NIR or true NDVI.

## 7. Final model architecture

The selected model is a customized SegFormer-B2
implemented using PyTorch and Hugging Face Transformers.

### 7.1 Mix Transformer encoder

| Stage | Hidden dimension | Transformer depth |
|---|---|---|
| 1 | 64 | 3 |
| 2 | 128 | 4 |
| 3 | 320 | 6 |
| 4 | 512 | 3 |

The encoder uses hierarchical multiscale representations,
overlapping patch embedding, efficient self-attention
and Mix-FFN blocks.

The architecture is suitable for agricultural objects
at different spatial scales, including small cotton bolls
and large stressed vegetation regions.

Exact attention heads, reduction ratios, patch sizes,
strides and other configuration parameters must be
verified from the actual SegformerConfig.

### 7.2 Nine-channel input adaptation

The original three-channel patch embedding convolution
is replaced by a nine-channel convolution.

Initialization:

W_new[:,0:3,:,:] = W_old / 3

W_new[:,3:9,:,:] = 0

The original convolution bias is copied when present.

The additional six channels learn during training.

Configured pretrained encoder: nvidia/mit-b2.

The implementation supports pretrained weight loading
and initialization from a previous checkpoint.

The actual V11 initialization lineage must be verified
from historical training records.

Do not claim V11 was necessarily trained from scratch.

### 7.3 MLP decoder

Decoder embedding dimension: 768.

Features from all four encoder stages are projected
and fused by the lightweight MLP decoder.

The segmentation head predicts seven classes.

Initial logits have approximately one-quarter of
the input spatial resolution.

Bilinear interpolation with align_corners=False
restores logits to the input spatial dimensions.

Training input shape:

(B,9,512,512)

Training output shape:

(B,7,512,512)

## 8. Training methodology

The training implementation combines class-weighted
focal loss, Dice loss and Lovasz-Softmax loss.

L_total = 1.0 L_focal + 2.5 L_dice + 1.0 L_lovasz

Focal loss:

L_focal = -alpha_t * (1-p_t)^gamma * log(p_t)

p_t is the predicted probability of the correct class.
alpha_t is the corresponding class weight.
gamma = 2.

Class weights use inverse pixel frequency:

w_c = N / (C * N_c)

N is total counted pixels.
C is the number of classes.
N_c is the class-specific pixel count.

Weights are clipped and manual overrides are applied.

Configured drought override: 10.
Configured cotton override: 8.

Dice loss:

L_dice = 1 - mean_c [
    (2 sum(p_c*y_c) + epsilon) /
    (sum(p_c) + sum(y_c) + epsilon)
]

Lovasz-Softmax provides an IoU-oriented surrogate objective.

Per-sample importance weights are applied to the focal
component, not all three loss components.

Ignore index 255 is excluded by the loss implementation.

The training implementation validates after every epoch
and saves the checkpoint with the highest validation mIoU.

CosineAnnealingLR is used with eta_min=1e-6.

Exact optimizer settings, augmentation probabilities,
sample weights and initialization lineage must be
verified against the actual training source.

- 1.20 from the drought class logit.

Other logits are unchanged by these adjustments.

The objective is to reduce excessive drought and dry-weed
predictions and improve class discrimination.

This is class-specific logit adjustment, not proof
of probabilistic confidence calibration.

Calibration was evaluated using validation data.

## 13. Large orthomosaic inference

Production inference uses sliding-window tiling.

Tile size: 1024 x 1024.
Stride: 768 pixels.
Overlap: 256 pixels.
Test-time augmentation: disabled.

Batch size is adapted to GPU memory availability.

Each tile is converted to nine channels and processed
by the selected model.

Overlapping predictions are combined using a
two-dimensional Hann weighting window.

For pixel x and class c:

A_c(x) = sum_i w_i(x) * p_i,c(x)

Final class = argmax_c A_c(x)

When all classes share a positive normalization
denominator, division does not change the argmax.

The implementation uses FP32 accumulation.

The rolling stitcher stores only the active vertical
accumulation region.

Rows are finalized when subsequent tiles can no longer
contribute to them.

Accumulator memory complexity changes from:

O(C*H*W)

to:

O(C*T*W)

T denotes tile height.

The full-resolution uint8 class map is retained.

Adaptive batch reduction handles CUDA out-of-memory errors.

Raw inference checkpoints preserve class maps and
associated metadata for safe continuation.

## 15. Physical area estimation

Ground sampling distance represents the estimated
ground length corresponding to one image pixel.

For GSD in millimeters per pixel:

pixel_area_m2 = (GSD_mm / 1000)^2

Class area:

area_c = N_c * pixel_area_m2

The valid-field area excludes background.

The agricultural footprint includes:

- Crop.
- Cotton ball.
- Drought.
- Dry weed.

It excludes soil, green weed and background.

The final field-specific GSD registry contains values
derived from available orthomosaic processing metadata.

The registry records image dimensions, altitude and
physical-scale verification status.

Physical areas are estimates.

Pulliah has a notable image-dimension mismatch.

Several smaller orthomosaics use local coordinates.

Unknown altitude is supported when a GSD override
is available.

## 16. Field-level visual stress decision

Define:

D = drought pixels / agricultural pixels

N = non-harvest drought pixels / agricultural pixels

C = largest connected drought component /
    total drought pixels

Decision signals:

S1 = D > 0.15

S2 = N > 0.10

S3 = C > 0.25

Visual stress flag:

S1 OR (S2 AND S3)

Heuristic stress score:

score = min(
    1,
    0.5 * D/0.15 +
    0.3 * N/0.10 +
    0.2 * indicator(S3)
)

The implementation rounds the score.

This is not a calibrated probability of drought.

S1 can trigger independently of non-harvest
and spatial-coherence signals.

The non-harvest drought fraction retains the
agricultural denominator.

Field confirmation is required before interpreting
the flag as actual agricultural drought.

## 21. Limitations

1. RGB imagery cannot uniquely establish drought causation.
2. Visual symptoms overlap with harvest, senescence,
   disease, nutrient deficiency and other stress factors.
3. The validation split contains source-image overlap.
4. Independent human-annotated testing remains pending.
5. Calibration was selected using validation data.
6. Pseudo-label errors may propagate into training.
7. Synthetic composites may not reproduce all natural
   agricultural spatial patterns.
8. Physical area estimates depend on GSD accuracy.
9. Some coordinate systems and image dimensions
   require further verification.
10. The heuristic stress score is not a probability.
11. Runtime comparisons use different GPU hardware.
12. Training accuracy and validation loss were not recovered.
13. Human-corrected labels are not necessarily independent
    of the original pseudo-labeling process.
14. No measured annotation-time reduction is established.

These limitations must be explicitly acknowledged.
